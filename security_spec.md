# Security Specification: WE GLOW Wellness Spa

## Data Invariants
1. **Appointments**: Must belong to the authenticated user who created them. Only admins can view all appointments.
2. **Services**: Publicly readable, but only writeable by authenticated admins.
3. **Users**: Users can only read/write their own private profile data. Roles cannot be self-assigned.

## The "Dirty Dozen" (Attack Payloads)
1. **Identity Spoofing**: Attempt to create an appointment with another user's `userId`.
2. **Privilege Escalation**: Attempt to update a user document to set `role: 'admin'`.
3. **Resource Poisoning**: Create a service with a 1MB string in the `name` field.
4. **State Shortcutting**: Update an appointment status directly from 'confirmed' to 'cancelled' without ownership.
5. **Orphaned Writes**: Create an appointment without a valid service reference.
6. **Negative Pricing**: Create a service with `price: -100`.
7. **Cross-Tenant Leak**: User A attempts to `get()` an appointment document belonging to User B.
8. **Unverified Booking**: Attempt to book without email verification.
9. **Shadow Field Injection**: Create a service with an extra `isVerified: true` hidden field.
10. **Timestamp Fraud**: Provide a client-side `createdAt` timestamp from the future.
11. **Mass Deletion**: Unauthorized user attempts to prune the `services` collection.
12. **Query Scraping**: Attempt to `list()` all users without specific filters.
